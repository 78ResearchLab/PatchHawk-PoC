# PatchHawk Proofs of Concept

This repository publishes vulnerability proofs of concept automatically
generated by PatchHawk. Each directory contains a technical write-up,
reproduction steps, and a comparison between vulnerable and fixed versions.

Follow [PatchHawk on X](https://x.com/patchhawk_) for updates.
